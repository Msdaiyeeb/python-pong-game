# Python Pong Game

A classic Pong Game developed using Python Turtle graphics and object-oriented programming concepts. The project is organized into multiple modules for better code structure and maintainability.

## Features

* Two-player paddle controls
* Ball movement and collision detection
* Dynamic score tracking
* Paddle bounce mechanics
* Modular code structure
* Smooth gameplay using Turtle graphics

## Project Structure

* main.py — Main game loop
* pad.py — Controls paddle behavior
* ball.py — Handles ball movement and collisions
* score.py — Manages score display and updates

## Technologies Used

* Python
* Turtle Graphics
* Object-Oriented Programming (OOP)
